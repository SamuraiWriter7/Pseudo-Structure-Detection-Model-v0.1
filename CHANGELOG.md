# Changelog

All notable changes to this project will be documented in this file.

This project follows a simple versioned changelog approach inspired by Keep a Changelog and Semantic Versioning.

## [0.1.0] - 2026-04-06

### Added
- Initial public release of **Pseudo Structure Detection Model v0.1**
- Core conceptual definition of pseudo-structure detection
- Human-readable project overview in `README.md`
- YAML specification for PSDM v0.1 in `yaml/`
- JSON Schema for machine-validated structure in `schema json/`
- Sample JSON payload in `sample json/`
- Base repository license
- Initial repository structure for future extension and validation workflow support

### Notes
- This version establishes the first detection model for identifying structurally plausible but weakly grounded or trace-deficient outputs
- Future versions may expand scoring logic, detection categories, interoperability, and reporting format
